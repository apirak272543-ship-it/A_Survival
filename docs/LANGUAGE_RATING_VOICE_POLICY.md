# A-Survival Language, Content Rating, and Voice Policy

สถานะเอกสาร: **ใช้งานเป็น policy ของ vertical slice แต่ยังไม่ใช่การรับรองเรตตามหน่วยงานภายนอก**

## ภาษาหลัก

ภาษาไทยเป็นค่าเริ่มต้นของเกม ใช้ภาษาไทยแบบที่คนทั่วไปอ่านเข้าใจง่าย เป็นภาษาพูดที่ไม่ราชาศัพท์และไม่ประดิษฐ์คำสวยหรูเกินจำเป็น ปุ่ม เมนู คำเตือน การบันทึก ความปลอดภัย ข้อมูลการควบคุม และข้อความ integrity ต้องสั้น ตรง และไม่กำกวม

เกมไม่ใช่เกมสำหรับเด็ก บทพูดของ NPC ตัวละคร และเสียงพากย์จึงใช้ภาษากันเองหรือคำหยาบได้เมื่อเหมาะกับบุคลิก ฉาก และเรตของเนื้อหา แต่คำหยาบไม่ควรถูกใส่เพื่อความหวือหวาในข้อความระบบ และห้ามใช้ในคำเตือนด้านความปลอดภัย การยืนยันการลบ/ย้ายข้อมูล ข้อความเกี่ยวกับบัญชี หรือข้อความที่อาจทำให้ผู้เล่นเข้าใจกติกาผิด

## การแยกข้อความ

| ชั้นข้อความ | แนวทาง | สถานะ |
|---|---|---|
| ระบบ/ความปลอดภัย/Integrity | ภาษาไทยชัดเจน ตรงประเด็น ไม่ใช้คำหยาบ ไม่ใช้คำกำกวม | ใช้เป็นเกณฑ์ตรวจทุก UI |
| HUD/การควบคุม | ใช้คำสั้น อ่านทันทีบนจอมือถือแนวนอน | กำลังปรับปรุงตาม vertical slice |
| NPC/บทสนทนา | ใช้ภาษาพูดตามบุคลิกและบริบทของผู้เล่นโตขึ้นได้ | ยังไม่มี voice/content pass ครบทุกบท |
| คำอธิบายพืช/เอฟเฟกต์ | แยกข้อมูลพฤกษศาสตร์อ้างอิงออกจากเอฟเฟกต์สมมติในเกม และไม่ทำ medical claim | ใช้ fictional-effect caps แล้วบางส่วน |
| เครดิต/ลิขสิทธิ์ | ใช้ถ้อยคำตรวจสอบได้ ไม่อ้างเจ้าของผลงานเกินหลักฐาน | มี Credits/provenance sheet แล้ว |

## ภาษาอังกฤษและความครบถ้วน

Thai เป็น locale ที่ใช้งานจริงของ slice นี้ ส่วน English option จะไม่ถูกนำเสนอว่าเป็น full localization จนกว่าจะมี resource ครบทุกข้อความและผ่าน visual review. หากยังไม่พร้อม ให้แสดงสถานะว่า **กำลังเตรียมชุดภาษา** หรือซ่อน option ที่ยังไม่มี resource แทนการทำปุ่มเลือกภาษาที่เปลี่ยนได้เพียงบางข้อความ

## เสียงพากย์

เสียงพากย์เป็นระบบเสริม ไม่จำเป็นต่อการเข้าใจกติกา ผู้เล่นต้องอ่านข้อมูลสำคัญได้แม้ปิดเสียงหรือไม่มีไฟล์เสียง ระบบจะใช้เฉพาะไฟล์ที่มี provenance/license ที่ตรวจสอบได้ และจะไม่อ้างว่าเสียงใดเป็นเสียงของบุคคลหรือ provider หากยังไม่มีหลักฐาน ผู้ใช้สามารถตั้งระดับเพลงและเสียงเอฟเฟกต์ได้ ส่วน voice pack และ voice direction เต็มระบบยังเป็นงานภายหลัง

## เกณฑ์ก่อนประกาศว่า language/rating pass เสร็จ

ต้องตรวจข้อความสำคัญของ landing, identity, lobby, map, home, game HUD, settings, chest, Codex, Credits, integrity, offline และ AI NPC ให้เป็นภาษาไทยที่สม่ำเสมอ ต้องมี content disclosure สำหรับผู้เล่นโตขึ้นโดยไม่ใช้คำโฆษณาเกินจริง ต้องทดสอบว่าข้อความความปลอดภัยยังอ่านชัดเมื่อมีบทพูดกันเอง และต้องยืนยัน voice assets/license กับ mobile text layout ก่อนเปลี่ยนสถานะจาก `PARTIAL`.
