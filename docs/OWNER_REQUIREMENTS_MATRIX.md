# A_Survival — Owner Requirements Completion Matrix

> เอกสารนี้เป็น source-of-truth สำหรับตรวจคำสั่งของเจ้าของที่ปรากฏในแชทนี้ ไม่ใช่รายงานว่างานเสร็จแล้ว สถานะจะเปลี่ยนเป็น `VERIFIED` ได้เมื่อมี source implementation และหลักฐานการทดสอบ/ภาพจริงตรงกับเกณฑ์รับงานเท่านั้น

## สถานะที่ใช้

| สถานะ | ความหมาย |
|---|---|
| `VERIFIED` | มี implementation ใน owner ที่ถูกต้อง และมี test/browser/build evidence ที่ตรวจแล้ว |
| `PARTIAL` | มีโครงสร้างหรือ prototype แล้ว แต่ยังไม่ครบพฤติกรรมหรือยังไม่ผ่านภาพจริง/end-to-end |
| `PENDING` | ยังไม่มี implementation ที่ตรง acceptance criteria หรือยังไม่มีหลักฐานเพียงพอ |
| `BLOCKED-BY-QUESTION` | ต้องยืนยันข้อมูลจากเจ้าของก่อนจึงตัดสิน behavior ได้ |
