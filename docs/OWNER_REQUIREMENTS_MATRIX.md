# A_Survival — Owner Requirements Matrix

เอกสารนี้เป็น source of truth ของคำสั่งจากการสนทนาทั้งหมดที่ทบทวนถึงวันที่ 27 สิงหาคม 2026 ใช้สถานะ `VERIFIED` เฉพาะรายการที่มี source/test/evidence รองรับจริง, `PARTIAL` เมื่อมีฐานบางส่วนแต่ acceptance ยังไม่ครบ และ `PENDING` เมื่อยังไม่มี implementation ที่ตรวจสอบได้ ห้ามสรุปว่างานเสร็จทั้งหมดตราบใดที่รายการใน scope ยังเป็น `PARTIAL` หรือ `PENDING`
