
## Persistence result

หลังเข้า gameplay พบว่า `/games` ถูก mount เป็น IDBFS และโลก `New expedition` มี `chunks.dat`, `entities.dat`, `level.dat_old` และ `level.dat` อยู่จริง จากนั้นกด `Escape` และ `Quit to title` แล้วกลับเข้า `Select world` พบรายการ `New expedition` พร้อม preview image, timestamp, Survival mode และรายละเอียดโลกครบถ้วน จึงยืนยันได้ว่า save และ world-list reload ทำงานใน session เดียวกันบน Web.
