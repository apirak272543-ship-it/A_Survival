
## Persistence result

หลังเข้า gameplay พบว่า `/games` ถูก mount เป็น IDBFS และโลก `New expedition` มี `chunks.dat`, `entities.dat`, `level.dat_old` และ `level.dat` อยู่จริง จากนั้นกด `Escape` และ `Quit to title` แล้วกลับเข้า `Select world` พบรายการ `New expedition` พร้อม preview image, timestamp, Survival mode และรายละเอียดโลกครบถ้วน จึงยืนยันได้ว่า save และ world-list reload ทำงานใน session เดียวกันบน Web.

## Touch regression result

หลังปรับ safe-area margin 8px แล้ว browser screenshot ยืนยันว่า Select World วาง Back และ Create new ห่างจากขอบซ้าย/ขวา และ Create Expedition วาง header/back ห่างจากขอบบนพร้อม Begin เว้นขอบล่าง ปุ่มยังใช้งานผ่านเส้นทาง username → Start Game → Select world → Create Expedition ได้ตามเดิม ทั้ง Desktop และ Web build link ผ่านหลังการแก้ไข.
